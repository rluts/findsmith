'''FindSmith is under development and is not ready for production use. Review every proposed change carefully before saving it to Wikimedia.'''

'''[https://findsmith.toolforge.org FindSmith]''' is a browser-based find-and-replace workspace for Wikimedia projects, inspired by AutoWikiBrowser. It builds a list of pages, applies your rules in order, and lets you review and save changes one page at a time. It does not run unattended edits.

== Sign in ==

On the home page, select '''Log in with Wikimedia'''. FindSmith signs you in through Meta-Wiki; you do not need to sign in separately to each project wiki.

== Create a project ==

Open '''Your Projects''', enter a project name, choose a wiki from the shared list, and select '''Create project'''. A project uses one wiki at a time. You do not need to add a wiki that is already in the list.

If the wiki you need is missing, open '''Add Wiki''' and enter its Wikimedia domain, for example <code>en.wikipedia.org</code>. FindSmith checks that wiki's protected <code>Project:AutoWikiBrowser/CheckPageJSON</code> and loads its namespaces. The new wiki is available to all FindSmith users; it only needs to be added once. Then return to '''Your Projects''' to create your project.

FindSmith checks whether your account appears in that wiki's <code>enabledusers</code> or <code>enabledbots</code> list. If access is missing or cannot be verified, you can still review pages, but you cannot save edits. The project page also shows the account's groups on the selected wiki. Follow that wiki's editing and automation policies before using FindSmith.

== Choose pages ==

In '''Make list''', open '''Page sources and filters'''. Add one or more sources and enter one value per line where an input is shown. Available sources are manual titles, category members, backlinks, template transclusions, wiki search, your watchlist, user contributions, links on a page, categories on a page, and redirects to a page. Select the namespaces to include and set '''Maximum pages''' (up to 500). Then select '''Build page list'''. FindSmith normalizes titles and removes duplicates.

The Page list shows each page's status. Click a title to inspect that page. You can reorder or remove entries, append titles, or clear the queue. '''List tools''' can filter by title or status, sort the list by title, compare the queue with pasted titles, and export a CSV file. Rebuilding the list starts a new review.

== Define replacements ==

Select '''Add rule''' in the '''Rules''' tab. Rules run in the order shown; use the arrows to reorder them or the checkbox to disable one. Operations include find and replace, append or prepend wikitext, add/remove/replace a category, rename a template, and set/remove a template parameter.

For find and replace, enter '''Find''' and '''Replace with'''. Leave '''Replace with''' empty to remove matches. Choose literal text or '''Regex''', case sensitivity, and first match or all matches. Regex rules also have multiline and dot-matches-newline options. Replacement rules can protect selected wikitext regions, such as comments, references, links, headings, and templates. FindSmith uses Rust regex syntax; expressions written for AutoWikiBrowser's .NET regex engine may need adjustment.

Give a rule a name and select '''Save to my rules''' to reuse it in other projects. Rule names do not have to be unique. '''Add to project''' copies a saved rule into the current project.

Before building a list, you can enter a title in the '''Preview''' panel to test the current rules on one page without editing Wikimedia.

== Review and save ==

For each page, compare the proposed text with the current revision in the side-by-side diff. The '''Preview''' switch asks the selected wiki to render the proposed wikitext. Select '''Refresh preview''' after changing the text. Open '''Proposed wikitext''' to edit it manually. The diff updates shortly after you stop typing, and saving waits for it; if the update fails, select '''Recompute diff''' to try again. If there is no change, FindSmith shows '''No diff''' and disables saving.

'''Save and next''' publishes the change and moves to the next page; see below. '''Skip''' records a skip and moves on. '''Previous''' returns to an earlier page. Your progress is kept, so you can close FindSmith and come back later. '''Resume review''' appears when a stopped review can continue, for example after a failed save. Use '''Ctrl+Enter''' or '''⌘+Enter''' for Save and next and, when no input has focus, '''P''' for Previous or '''S''' for Skip. '''Skip pages without changes''' can inspect pages ahead of review and skip those without changes.

To publish a reviewed change, acknowledge the wiki's editing policies once for the review and select '''Save and next'''. FindSmith suggests an edit summary from the first enabled find-and-replace rule; if the complete summary would exceed 500 characters, it uses <code>Autoreplacement</code> instead. You can edit the summary text, but FindSmith always appends <code>using [[User:RLuts/FS|Findsmith]]</code> and does not let you edit that attribution. Select '''Minor edit''' only when allowed. '''Bot edit''' is available to accounts in the <code>bot</code> or <code>flood</code> group that also have the <code>bot</code> right; the backend checks this again when saving. FindSmith checks current edit permissions and the page revision before submission. If the page has changed, reload and review it again rather than saving an outdated version.

The '''Status''' tab shows review progress and decision history, including saved revisions and skip reasons. You can click a '''reviewed''' page in the Page list and save it later, even after the review is complete. You can also click a '''skipped''' page, edit it, and save it; FindSmith still shows why it was skipped. After saving, FindSmith selects the next '''reviewed''' or '''pending''' page. After changing rules, select '''Apply rules''' to review the page list with the updated rules.

== Limitations ==

FindSmith supports a Wikimedia wiki only after someone adds it to the shared list. To add it, the wiki must have a <code>Project:AutoWikiBrowser/CheckPageJSON</code> page protected from editing by non-admins. Its text must be JSON with <code>enabledusers</code> and <code>enabledbots</code> lists. To save edits, your account must appear in one of those lists and have the required edit rights on that wiki. You can still review pages if your account is not listed, but you cannot save them. There is no unattended editing; each '''Save and next''' submits at most one reviewed page. The interface is currently in English.
